기물 움직이는 방법

판은 보이지 않아요. 수를 글자로 입력해서 두세요.

  • 폰은 칸 이름만 써요: e4, d5
  • 다른 기물은 기물 글자 + 도착 칸이에요: Nf3, Bc4, Qh5
    N 나이트 · B 비숍 · R 룩 · Q 퀸 · K 킹 (반드시 대문자)
  • 잡을 때는 x를 넣어요: Nxe5, 폰은 exd5
  • 캐슬링은 알파벳 대문자 O로 써요: O-O (킹사이드), O-O-O (퀸사이드)
  • 프로모션은 e8=Q 처럼 써요.
  • 같은 기물 2개가 같은 칸에 갈 수 있을 때는 열이나 줄을 붙여요: Nbd2, R1d3

둘 수 없는 수를 입력하면 안내가 나오고, 다시 입력하면 돼요. 게임이 끝나면 체스판으로 기보를 볼 수 있어요.

기물 이동법 다시 보기
  • 폰: e4 / 기물: Nf3, Bc4, Rd1, Qh5, Ke2
  • 잡기: Nxe5, exd5 / 캐슬링: O-O, O-O-O
  • 프로모션: e8=Q / 구분: Nbd2, R1d3

상대가 무승부를 제안했어요.
